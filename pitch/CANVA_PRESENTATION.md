### Макет:
```

│   ┌─────────────────────────────────────────────┐    │
│   │ 1 мошенник = 10 фейковых аккаунтов          │    │
│   │ = фейковый "опт" без реальных покупателей   │    │
│   │ Pinduoduo тратит $100M+/год на анти-фрод     │    │
│   └─────────────────────────────────────────────┘    │
│                                                      │
│   РЕШЕНИЕ:                                           │
│   ┌─────────────────────────────────────────────┐    │
│   │                                             │    │
│   │   📱 eSIM = 1 устройство = 1 участник       │    │
│   │                                             │    │

│                                                      │
│   АРХИТЕКТУРА:                                       │
│   [App] → [SIM/eSIM ID Layer] → [Commerce Layer]     │
│            ↑ GSMA Open Gateway                       │
│            Стандарт работает — не концепция          │
│                                                      │
└──────────────────────────────────────────────────────┘
```

### Текст слайда:
**Заголовок:**
> SIM/eSIM — слой, который делает группы настоящими

**Проблема (красная карточка или с иконкой ⚠️):**
> Главная атака на группбай:
> 1 человек → 10 фейк-аккаунтов → фейковый «опт»
> Pinduoduo тратит сотни миллионов на анти-фрод ежегодно

**Решение (зелёная карточка):**
> eSIM-идентификация: 1 устройство = 1 подтверждённый участник
> Стоимость фейкового аккаунта: $0.1 → **цена смартфона**
> Вход без SMS: оператор подтверждает абонента на сетевом уровне

**Архитектура (простая схема):**
> **App** → **SIM/eSIM Identity** → **Commerce Engine**
> (GSMA Open Gateway / Number Verification API — работающий стандарт)

**Для оператора:**
> 💼 Для оператора: новый revenue stream — identity-as-a-service

### Визуал (что вставить):
- **Диаграмма архитектуры** — нарисуй в Canva:
  - 3 прямоугольника в ряд: "📱 App" → "🔐 eSIM Identity" → "🛒 Commerce"
  - Стрелки между ними
  - Под средним блоком: "GSMA Open Gateway"
- **Screenshot верификации** из приложения: `pitch/01-welcome.jpeg` или экран с eSIM-анимацией
- **Иконка замка** 🔐 большая, слева или сверху — символизирует безопасность
