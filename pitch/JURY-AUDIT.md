## ✅ Что подтверждено прогоном

- Онбординг свежего профиля: телефон-валидация, eSIM-анимация (4.2с), EID генерится, device-bound.
- Персонализация реально работает: профиль «Айгерим, Шымкент, beauty+home, 30k» → подборка и лента перестроились (Calvin Klein, Olay…), чипы «почему» корректны.
- KK-локализация: все ключевые экраны переведены, переключение мгновенное.
- Join-флоу: шит с холдом → конфетти → «Топ жиналды!» → статус в «Мои группы».
- Трип-тап симуляция: «Тимур (Шымкент) топқа қосылды», счётчик двигается + broadcast.
- QR-оверлей открывается/закрывается.
- Realtime: событие от внешнего клиента двигает счётчик в UI (проверено ранее: 10→11).

## Отчёт техсудьи (ревью кода, 22 файла)

### CRITICAL
- `realtime.ts:8` — CLIENT_ID читает localStorage на module-уровне без try/catch → Safari private mode = белый экран всего приложения.
- **`public/vectors.json` не существует** → «умный поиск» мёртв в любом деплое, и провал замаскирован: SPA-rewrite отдаёт index.html с кодом 200 на /vectors.json → тихий fallback. (Оживёт после ключей + embed-скрипта, но маскировку надо убрать: проверять content-type.)
- Guard теряет QR-ссылку: после онбординга гость попадает в /feed, а не на отсканированный товар.
- **Расхождение счётчиков между устройствами by design:** extraMembers в localStorage + broadcast без replay → свежеоткрытый телефон судьи видит «5/6», проектор — «6/6 🎉». На сцене это заметно. Полный фикс = таблица состояния групп (день 2, решение).
- `DailyPick.tsx` — кэш парсится без try/catch и без перепроверки id по каталогу → битый кэш или смена каталога = краш ленты.

### MAJOR
- **Таймер заморожен:** для не-joined групп deadline пересчитывается на каждый рендер → «26ч 00м» никогда не тикает. Судья заметит за 2 минуты.
- Двойной тап «Заморозить» = двойной broadcast (+2 участника у всех зрителей).
- Нет верхней границы вступлений: «18/16 участников» возможно.
- Открытый broadcast-канал: любой с DevTools накручивает счётчики и спамит тосты во время демо (анти-фрод история продукта vs накручиваемый канал — ирония, которую судья может поймать).
- API /pick и /search без rate-limit — публичный прокси к LLM-ключам.
- «PWA» в питче — а manifest.json и service worker отсутствуют. Либо добавить, либо не произносить слово PWA.
- Hot-рейл и рекомендации мемоизированы намертво — live-джойны не двигают «почти собраны».

### MINOR (выжимка)
- Конфетти при каждом открытии собранной группы; /p/несуществующий-id → белый экран; «Вы» в аватарах не переведён на KK; «286 групп» — захардкожено; имя без maxLength уходит в LLM-промпт; кэш подборки не сбрасывается при смене профиля.

### Вопросы, которые задаст технический судья (готовить ответы)

**Оценка техсудьи: 6.5/10** — «полированный клиентский прототип ощущений, а не работающая механика коллективной покупки». Сильно: LLM-fallback chain, прекомпьют эмбеддингов, чистый TS. Слабо: вся групповая механика — инкремент в localStorage.
