# eSIM — креативные применения для group-buy (брейншторм для жюри-телекома)

> Дополняет [`ESIM.md`](ESIM.md) (база/анти-фрод). Здесь — НЕочевидные применения,
> которые превращают SIM из «фичи» в несущую стену продукта. Проверено по актуальному
> списку CAMARA (Fall '25, 60 released APIs).

## Нарратив одного слайда

**Сеть оператора закрывает ВСЮ воронку group-buy, которую интернет-маркетплейс закрыть не может:**

> Кто ты *(Number Verification + KYC Tenure)* → где ты *(Geofencing + Region Device Count)*
> → с кем *(SIM-граф)* → как платишь *(Carrier Billing reserve/capture)*
> → когда вернёшься/онлайн *(Roaming + Reachability)*.

Один verified identity-and-location слой вместо пяти разных интеграций. У Kaspi/Pinduoduo
этого нет — у них нет tamper-proof сигнала местоположения и идентичности на уровне соты.

## Две опорные идеи (ставить в питч)

### КИЛЛЕР — «Живой термометр групп по районам»
Карта города разбита на районы/ЖК. С согласия пользователя **Geofencing Subscriptions**
ловит, что он физически дома в своём ЖК, а **Region Device Count** показывает в реальном
времени: «в твоём районе уже 7 человек ждут эту же сковородку — не хватает 3 до бесплатной
общей доставки». Группа собирается по **физической близости**, а не по соцсети → снимает
главную боль group-buy в РК: последнюю милю. Одна машина в один ЖК вместо 10 адресов.
**Почему незабываемо:** невозможно без сети оператора. GPS подделывается, сота — нет.
Телеком становится ядром механики, а не анти-фрод-костылём.
*API: Geofencing Subscriptions + Region Device Count + Population Density Data. Вау 9 · Реал 8.*

### ПРАКТИЧНАЯ — «Групповой эскроу со счёта телефона»
Two-step **Carrier Billing** = reserve → capture. На старте группы телеком *резервирует*
(холдит) сумму на счёте телефона каждого участника, не списывая. Группа собралась → один
`capture` по всем; не собралась → авто-`refund`. Решает фундаментальную боль group-buy
(«заплатил, а группа не собралась») И работает **без банковской карты** — критично для
регионов РК с низким карточным проникновением. Это наш текущий «холд» — но настоящий,
на телеком-рельсах.
*API: Carrier Billing (reserve/capture) + Carrier Billing Refund. Вау 9 · Реал 9.*

## Остальные сильные (по убыванию вау×реал)

| Идея | Суть | API | Вау·Реал |
|---|---|---|---|
| **Tenure-лимит доверия** | Чем дольше номер у оператора, тем выше сумма холда без предоплаты и больше групп можно организовать. Новый номер (признак фрода/перекупа) = малый лимит. Геймифицированная репутация организатора | KYC Tenure + SIM Swap (сменили вчера → лимит обнулён) | 8·9 |
| **Roaming-триггер «собери из Китая»** | Казахстанский номер роумится в Гуанчжоу → пуш «собери групповую закупку с Taobao сейчас, земляки в Алматы оплатят долю, везёшь общим карго». Турист/челнок = узел трансграничной сети | Device Roaming Status (+Subscriptions) | 9·7 |
| **SIM-граф = виральный движок** | Инвайт по номеру: Number Verification подтверждает реального человека (не фейк), структура «кто-кого-позвал» = реферальное дерево, защищённое от накрутки на уровне сети | Number Verification + Population Density | 7·8 |
| **«Заказ вернулся домой»** | Geofencing/Roaming ловит возврат из-за границы → «пока тебя не было, твой ЖК собрал 3 группы, забери у дома» | Roaming Status Subscriptions (roaming→home) + Geofencing | 7·8 |
| **Reachability — умный добор** | Группа почти собрана, нужен последний платёж → Device Reachability показывает что должник онлайн ПРЯМО сейчас → пуш в нужный момент, не в пустоту | Device Reachability Status | 6·8 |

## Отброшено честно (чтобы не спалиться перед телеком-жюри)

- **Network Slicing / QoD / QoS Booking** — к group-buy не клеится. Это про гарантию полосы
  для стриминга/гейминга. Притянуть = маркетинговая чушь, телеком-жюри раскусит мгновенно
  и зачтёт как непонимание. **Не трогать.**
- **Blockchain Public Address** — решение в поиске проблемы. Нет.
- **Most Frequent Location** для авто-района — privacy-токсично, дублирует Geofencing с худшим
  согласием. Geofencing/Region Count чище.

## Что из этого можно ПОКАЗАТЬ в демо (mock-UI, по ТЗ реализация не требуется)

1. **Термометр района** — на карточке/ленте мок-блок «в вашем районе (Есиль, Астана) ждут 7 →
   нужно ещё 3 до бесплатной доставки». Визуально мощно, объясняет киллер-идею за 3 секунды.
2. **Carrier Billing в join-шите** — опция оплаты «со счёта телефона» рядом с холдом
   (у нас уже есть холд-механика — добавить лейбл «через Carrier Billing, без карты»).
3. **Tenure-бейдж организатора** — в профиле «номер 5+ лет → доверенный организатор,
   лимит холда до X ₸».
